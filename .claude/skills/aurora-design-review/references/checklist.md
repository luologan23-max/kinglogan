# Aurora 网站审查清单

每项后面括号里是怎么查。「probe」指 `AURORA_PROBE=1` 渲染时生成的 `.json` 测量结果；「report」指诊断包的 `report.json`。

## 1. 信任感（第一屏决定买家敢不敢询价）
- 首页首屏 5 秒内能看出：卖什么（古巴雪茄）、在哪（迪拜 JAFZA 持牌）、为什么可信（Habanos 官方渠道、原装不拆封、防伪可查）、怎么买（WhatsApp）。（首页电脑/手机首屏截图）
- 年龄验证 21+ 弹窗存在且文案清楚，确认后不会反复弹。（插件 `aurora-age`；HTML 里有 `.aurora-age`）
- 公司名、牌照、地址、WhatsApp 号码在页脚和关于页一致。（页脚 HTML、`page_about`）
- 防伪查验页能用，链接到 Habanos 官方查验方式。（`page_verify`）
- 没有占位文字、lorem、「Uncategorized」、空分类、「Hello world」。（全文搜索 HTML）

## 2. 找货
- 导航栏目和实际分类对得上；「腓尼基限量」「年度限量」页面有内容或有像样的空状态。（导航链接 vs report.categories / 页面 HTML 里的商品数）
- 品牌标签、筛选按钮（有现货、罗布图、鱼雷、丘吉尔、Behike）点了有结果，计数正确。（商店页 HTML 的 `.aur-filter-count`）
- 每个品牌下的产品数量合理，没有重复款（同名产品）。（report.products.duplicate_names）
- 中文名和英文名都能被找到；产品排序有逻辑（品牌 → 系列 → 尺寸），不是导入顺序。

## 3. 商品卡
- 图片：同一屏里风格统一（实拍白底横放 vs 品牌深色渲染图）；雪茄完整可见、不被裁掉两端。（report.products.items[].image_srcs、照片对照页）
- 层级：品牌小标题 → 产品名 → 价格 / 联系询价，一眼能扫完；产品名过长时两行内截断而不是撑高卡片。（截图）
- 状态角标（可调货 / 现货）含义清楚、颜色一致。
- 「＋」加入清单和 WhatsApp 按钮在手机上能直接点到（触屏没有悬停）。（probe smallTargets、手机截图）

## 4. 产品页
- 首屏：中文名、英文名、状态、价格或联系询价、WhatsApp 主按钮都在手机首屏内。（手机截图首屏 844px 高）
- 图片框里的实拍图横放居中；缩略图能切换；整盒照片在图集里。
- 规格表没有空行、没有「undefined」；单个格子的跨列规则正常（`.aur-sg-wide`）。
- 名称待核对的红字只在管理员/预览模式出现。（`#aurora-review-css` 只在这两种情况下输出）
- 相关产品区块图片和名字正常。

## 5. 询价转化
- WhatsApp 链接号码正确（+971 585598868），预填文字带产品中英文名、数量、页面链接；清单整单发送格式清楚。（HTML 里 `wa.me` 链接的 text 参数）
- 「我的需求单」页面：加入、改数量、删除、发送都能用；清单为空时有引导。（`page_my-request`、`tests/integrate_bridge_test.js`）
- 旧的「询价」页（request-quote）跳到需求单，不是 503 或空白。（report.pages_html 里的 redirects）
- 浮动按钮不遮挡底部操作条或页脚内容。（手机截图底部）

## 6. 手机
- 没有横向滚动。（probe overflow 应为 0）
- 中文 ≥ 12px、英文小标签 ≥ 10px。（probe smallText）
- 点按区 ≥ 40px（理想 44px），相邻按钮间距够。（probe smallTargets）
- 固定底部操作条不遮挡最后的内容（页面底部留出操作条高度）。
- 首屏不被导航 + 滚动条 + 年龄弹窗占满。

## 7. 一致性
- 颜色只来自设计变量；同一个变量没有两套值（`--gold-light`）。（样式表里搜 `:root`）
- 直角、无阴影：没有主题或插件带进来的圆角按钮、阴影卡片。（截图；样式表里搜 `border-radius`、`box-shadow`）
- 字体只用 Bodoni Moda / EB Garamond / Cormorant Garamond / Jost + 系统中文字体。
- 手写页面（首页、关于等）和商店页的按钮、标题样式一致。

## 8. 内容完整度
- 在售产品都有图（实拍或品牌图）、有中文名、有规格；价格空着的显示「联系询价」。（report.products.items）
- 草稿里有没有该上架的（例如补好资料的限量款）。（status=draft 且 meta.aurora_review 已清空）
- 关于、FAQ、批发、配送条款内容是最新的，没有互相矛盾的说法（运费、起订量、付款方式）。

## 9. 可读性与无障碍
- 正文、价格、按钮文字对比度 ≥ 4.5（大字 ≥ 3）。已知 `--ink-light`、`--gold` 在奶油底上约 2.6，只能做装饰或大字。（probe lowContrast）
- 图片有 alt（产品名）；图标按钮有 aria-label。
- 阿拉伯语切换后排版方向和长度没有把布局撑坏（需要时请用户截图）。

## 10. 性能
- 页面 HTML 大小（商店页约 300KB）、样式表数量（约 26 个）；停用的旧片段（#1–#10、#12、#16–#22）可以清掉。（report.snippets、report.css_map）
- 图片尺寸合理：实拍图上传时已限制在 2000px 内、去掉 EXIF；品牌图 1600×1600。
- 首页没有一次加载全部产品。

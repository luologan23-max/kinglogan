# Aurora Cigars 视觉规范

网站是迪拜自贸区（JAFZA）的古巴雪茄**询价站**：WooCommerce 只当产品库，没有购物车和结账，所有成交都走 WhatsApp。
买家以讲中文的高端客户为主，也有英文和阿拉伯语客户。设计的任务是让人觉得「这是一家可信的老牌雪茄精品店」，
然后顺手发 WhatsApp 询价——不是促销型电商。站点当前的风格叫 **Boutique Cream**（奶油底、墨色字、少量金色、直角细线）。

这份规范描述的是**线上已经在用的样子**（2026-10 从诊断包里量出来的），改动时要和它保持一致；
真要换方向（比如整体改深色），先和用户确认，再整站一起换，不要一页一个风格。

## 配色（CSS 变量，定义在站点自己的代码片段里）

| 变量 | 值 | 用途 |
|---|---|---|
| `--cream` | `#FAFAF8` | 页面底色、导航底色 |
| `--bg-warm` | `#F5F3EF` | 次级底色：产品页左侧图片栏、分区背景 |
| `--ink` | `#1A1A18` | 正文、标题、主按钮（黑底白字）、手机底部操作条 |
| `--ink-mid` | `#4A4A46` | 次要文字 |
| `--ink-light` | `#9A9A94` | 辅助标签——**和奶油底对比度只有约 2.6:1**，只能用在 ≥14px 的非关键文字上，小字请改用 `--ink-mid` |
| `--border` | `#E2E2DC` | 1px（导航 0.5px）细分隔线 |
| `--gold` | `#B8975A` | 点缀：品牌名小标题、Logo 的「Cigars」、选中态。**对比度约 2.6:1**，不要用来写正文或小于 14px 的关键信息 |
| `--gold-light` | `#F0E6D0`（另一处片段里是 `#F5EDD8`，不一致，用变量不要写死） | 金色浅底标签 |
| `--green` | `#1A9968` | 现货 / 在线状态小圆点 |
| WhatsApp 绿 | `#25D366` | 只用于 WhatsApp 按钮本身 |
| 图片框底色 | `#EDEAE4`（卡片）/ `#EAE6DE`（产品页相框，边框 `#CCC7BC`） | 图片加载前的底色 |

规则：新颜色先问自己能不能用上面已有的；确实需要（比如错误提示红）就加成变量。名称待核对的红字标记（`#C62828`）
是内部用的，只在预览模式 / 管理员登录时出现，不算设计的一部分。

## 字体

Google Fonts 已加载：`Bodoni Moda`（`--serif`，标题、产品名、价格）、`EB Garamond`（`--garamond`，英文斜体副标题）、
`Cormorant Garamond`（`--cormorant`）、`Jost`（`--sans`，按钮、标签、导航）。中文没有单独加载字体，走系统字体（苹方等）。

- 产品页：中文名 38px Bodoni（中文实际显示为系统宋/黑体），英文名 19px EB Garamond 斜体灰色。
- 商品卡：品牌小标题 9px Jost 大写、字距 .18em、金色；产品名 17px serif；价格 19px serif。
- 按钮和标签：Jost 11px 大写、字距 .12–.16em、粗 500–600。
- 中文不要小于 12px（现在顶部滚动条、角标里有不少 9px 中文，手机上很难读，这是已知问题）；英文大写小标签最小 10px。
- 不要再引入新的字体家族。

## 形状与质感

- **直角**：按钮、卡片、输入框、标签都是 `border-radius: 0`。插件的整合样式里专门把主题自带的圆角去掉了。
- **不用阴影**，层次靠 1px 细线和底色深浅。
- 大量留白，网格对齐；金色只做点缀，一屏里金色元素不超过两三处。
- 不用 emoji、不用渐变、不用大面积促销色块和倒计时之类的电商套路。

## 组件（选择器见 references/components.md）

- **顶部导航** `#aurora-nav`：奶油底、sticky；Logo「Aurora**Cigars**」；栏目「常规系列 / 腓尼基限量 / 年度限量 / 批发合作」；
  语言切换「中文 / EN / عربي」；右侧黑底「立即询价」。下面是一条滚动的信任信息条（持牌、官方渠道、原装不拆封、防伪可查、恒温仓储、DHL）。
- **商品卡** `.aur-card`：图片区 220px 高（手机 160px），`object-fit: cover`；左上角状态角标（如「可调货」）；
  下方金色品牌小标题 → 产品名 → 细线 → 价格（没价格显示「联系询价」）+ 右侧 WhatsApp 小方按钮；手机上图片右下角有「＋」加入询价清单。
- **产品页**：左栏 `--bg-warm` 底、sticky，正方形双线相框（最大 320px）+ 56px 缩略图；右栏中文名 → 英文斜体名 → 状态行 →
  「联系询价 · Enquire for Price」→ 黑底「WhatsApp 询价」主按钮 → 描边「加入询价清单」→ 四格服务说明（DHL / 原装封箱 / Habanos 正品 / EXW 迪拜）→ 规格表 → 品鉴。
  手机底部固定黑色操作条：数量、「询价」、绿色 WhatsApp、加入清单。
- **询价清单**：浮动按钮 `.aur-enquiry-float` + 「我的需求单」页面；整站唯一的转化路径就是 WhatsApp（单款询价或整张清单发送）。
- **年龄验证**：21+ 弹窗，进站先出现，这是合规要求，不要去掉或弱化。

## 产品图片的呈现

- 实拍图：白底正方形，雪茄**横放**在正中，两端各留约 6% 白边（上传时自动处理，详见 `aurora-product-photos`）；整盒照片放图集第二张起。
- 还没有实拍图的产品用品牌渲染图（深色背景斜放的雪茄）。两种图混在一个列表里会显得不统一——优先给常规系列补实拍图，
  或者把品牌图也改成白底横放的风格。
- 图片区都是 `object-fit: cover` 的正方形或接近正方形的框：任何新图都要按正方形来做，横条图直接上传会被裁成中间一截。

## 名称和文案

- 产品标题用**英文官方型号名**（如「Montecristo Open Slam」），中文名存在 `_name_cn`，产品页中文名在上、英文斜体在下。
  官方写法拿不准的产品会被标红「名称待核对」，改名前先看 `content/name-review.csv` 和 `content/name-fixes.csv`。
- 地区限量的长名字（如「Edición Regional Líbano …」）保持原样，不擅自缩写。
- 价格空着时显示「联系询价 · Enquire for Price」，不要显示 0 或「缺货」。
- 中英双语并列时中文在前；英文用于副标题和小标签。阿拉伯语切换存在，新增文案要考虑三种语言的长度差异。
- 语气：克制、专业、像雪茄店主；不用「爆款」「抢购」「限时」之类的词。

## 做设计决定时

1. 先看现状：要改的页面在诊断包里长什么样（`aurora-design-review` 讲怎么离线还原和测量）。
2. 用上面的变量和组件拼，不另起一套。
3. 手机和电脑都要看：断点主要是 921px 和 544px（沿用 Astra 主题）。
4. 落地方式（改哪个文件、怎么测试、怎么上线）看 `aurora-ui-change`。
